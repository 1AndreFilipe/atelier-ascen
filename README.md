# ATELIER — ASCEN

Website de demonstração para um estúdio português fictício de arquitetura e interiores. Next.js App Router, TypeScript e Tailwind CSS.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Validação

```sh
npm run typecheck
npm run build
```

## Publicação

Importar este repositório na Vercel, selecionar Next.js e publicar. Não são necessárias variáveis de ambiente. O diretório raiz é o deste ficheiro.

## Funcionalidades

- Página inicial cinematográfica; páginas de estúdio, serviços, contacto e privacidade.
- Seis projetos com rotas individuais, metadados e galerias de referência.
- Filtros por categoria, navegação móvel acessível e respeito pela preferência de movimento reduzido.
- Imagens responsivas otimizadas por next/image.
- Formulário com validação nativa e confirmação local. Não envia ou guarda dados; não simula um envio real.

## Transparência

Marca, projetos, áreas, datas e localizações propostas são fictícios. Não são inventados clientes, prémios ou obras realizadas. Fotografias de referência do Unsplash, identificadas como tal na interface. Para ligar contactos reais, implementar um serviço de envio e atualizar a política de privacidade antes da utilização comercial.
